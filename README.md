# Boltlane

Open-source, self-hostable residential-IP proxy network.

- **Peers** run a Go client on devices they own (Windows, Linux, macOS, Raspberry Pi; Android/iOS later) and get paid per byte served, in Bitcoin over Lightning.
- **Requestors** (apps like CitePulse, geo_optimize — later external paying customers) route HTTP/SOCKS traffic through real home IPs.
- **Servers** are self-hostable by anyone; payments default off. The SaaS exists only for network-effect scale.

Status: early planning. Architecture and specs live as [wayfinder map issues](../../issues) in this repo.
